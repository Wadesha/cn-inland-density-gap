# 内陆高密度 · 低发展区带 · 双变量地图

只看「人口密、发展弱」的内陆区带（胡线以东）。气泡位置为真实县界质心，颜色按
**密度 × 发展指数** 双变量着色：红 = 高密度 + 低发展（重点），蓝 = 高密度 + 高发展（同内陆对照）。

## 文件
- `index.html` — ECharts 地图应用。运行时从 DataV 加载中国县级底图，从 `data.json` 读取样本数据。
- `data.json` — 区县样本（名称 / 省份 / 人口密度人·km⁻² / 人均GDP元 / 类型 / 自然条件）。key 与底图 `properties.name` 对齐。

## 机制
人口密度的自然成因 = 农耕承载力（平坦冲积土 + 水/灌 + 积温两熟）；现代发展指数 = 非农附加值人均占有。
二者是两条因果链，「密而弱」是尺度错配而非真矛盾——农耕锁定把劳动力钉在农业上。

## 数据说明
当前为**示意样本**，数值为量级近似，非精确统计。扩维路径：
1. 接入七普人口密度 + 统计年鉴县级人均GDP / 非农就业占比（替换 `data.json`）。
2. 扩充到全县（当前仅覆盖抽样区县，底图其余区县为灰底上下文）。
3. 发展指数可换为复合现代化指数 / HDI / 卫星夜间灯光代理。

## 本地预览
因 `data.json` 用 fetch 加载，需经 http 访问（直接双击 file:// 可能被浏览器拦截）：
`python3 -m http.server` 后访问 `http://localhost:8000/`。
