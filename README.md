# 内陆高密度 · 低发展区带

只看「人口密、发展弱」的内陆区带（胡线以东）。红=高密度+低发展（重点），蓝=高密度+高发展（同内陆对照）。稀疏侧不在数据集内。

## 展示结构（钻取，避免一次性加载全县界）
- `index.html` — 省级入口。首屏仅加载省级底图（~1.3MB）；颜色越红=该省抽样的密而弱区县越多。点击省 →
- `province.html?code={省adcode前2位}` — 本省县级双变量填色图（按需加载该省县界，~0.5–1.5MB）。点击区县 →
- `place.html?name={区县名}` — 单地详情页：双变量矩阵定位、指标卡、自然条件、机制、同省/强对照、省内位置迷你图。

## 文件
- `echarts.min.js` — 本地化的 ECharts（国内源，非 jsdelivr）。
- `provinces.geojson` — 省级底图。
- `provinces/{pp}.geojson` — 按省拆分的县级几何（由原 26MB 全县界拆分，降低首屏传输）。
- `data.json` — 区县样本（名称/省份/人口密度人·km⁻²/人均GDP元/类型/自然条件）。名称与底图 `properties.name` 对齐。

## 机制
人口密度=农耕承载力（平坦冲积土+水/灌+积温两熟）；发展指数=非农附加值人均占有。二者是两条因果链，「密而弱」是错配（农耕锁定）。

## 数据说明
示意样本（量级近似）。扩维：接七普人口密度+统计年鉴县级人均GDP/非农就业 → 直接在 `data.json` 增补，几何已由 `provinces/` 覆盖全县，无需改动前端。
